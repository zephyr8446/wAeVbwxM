# 项目简介

## 核心功能
- 基于YOLOv8的牙齿X光目标检测系统，支持8类牙齿目标检测（Caries、Crown-Bridge、Filling、Implant、Post-screw、Root canal Obturation、crown、implant）
- 提供5023张标注数据集
- 包含完整源码、训练好的模型及训练结果
- 支持多种输入方式：单张图片、图片文件夹、视频文件、本地摄像头
- 界面功能：实时显示目标位置、目标总数、置信度；支持批量检测；检测结果保存
- 可自定义置信度和IOU阈值
- 支持选择显示标签和原图
- 可选择不同检测模型

## 适用场景
- 牙科医疗影像分析
- 牙齿健康状况自动评估
- 口腔诊所辅助诊断
- 牙科研究数据分析

## 技术特点
- 技术栈：Python3.9、OpenCV-Python、PyQt5、Ultralytics、Torch1.9
- 开发环境：PyCharm+Anaconda或VSCode+Anaconda
- 包含完整UI界面源文件和图标
- 已配置好运行环境，可直接使用
